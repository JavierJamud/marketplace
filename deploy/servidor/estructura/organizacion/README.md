# organizacion/: proyectos propios de ZeuDin Group

Cada subcarpeta es un proyecto de la empresa, con la estructura estándar descrita en `/opt/zeudin/README.md`.

Para agregar uno: `sudo /opt/zeudin/plataforma/scripts/nuevo-proyecto.sh organizacion <proyecto>`.

La lista actual con dominio, puerto y base de datos está en `/opt/zeudin/plataforma/registro/PROYECTOS.md`.
